# Bot Response Patterns

## Selling Bot (Digital Products)

### Welcome Message
```
🤖 <b>Welcome {name}!</b>

<i>{Product Name} Bot</i>

I'm here to help you {purpose}!

<b>📚 Commands:</b>
/questions — Free sample questions
/buy — Full PDF (₹299)
/syllabus — Exam pattern
/help — All commands

<i>Or ask me anything!</i>
```

### Buy Command Response
```
🛒 <b>BUY {PRODUCT NAME}</b>

📄 <b>Includes:</b>
• {Feature 1}
• {Feature 2}
• {Feature 3}

💰 <b>Price: ₹{price}</b>

<b>📱 Payment:</b>
UPI: <code>{upi_id}</code>
PhonePe/GPay: {number}

Screenshot bhejo after payment!
PDF delivered in {timeframe}
```

### Natural Language — Price Inquiry
Keywords: "price", "cost", "kitna", "rupees", "₹"
Response: Same as buy command

## Content/Exam Bot

### Syllabus Response
```
📋 <b>EXAM SYLLABUS (2016-2025)</b>

<b>{Exam Name}:</b>
• Subject 1: {Q count} ({coverage})
• Subject 2: {Q count} ({coverage})
• Subject 3: {Q count} ({coverage})

<b>🎯 High-Yield Topics:</b>
• Topic A + Topic B = X% marks
```

### Question Explanation Format
```
<b>{Subject} ({Topic}):</b>
<i>{Question}</i>
✅ {Short explanation}

<b>Solution:</b>
{Step-by-step}
Answer: {Answer}
```

## General Assistance Bot

### Greeting Responses (randomized)
- "Hello {name}! 👋 Kya help chahiye?"
- "Hey {name}! 🎉 Batao kya kar sakta hoon?"
- "Namaste! 🙏 Kya kaam hai aaj?"

### Motivation Response
```
💪 <b>MOTIVATION!</b>

Ruko mat! 🎯

• Thoda break lo
• Phir se shuru karo
• Main hoon na tumhare saath!

<i>All the best! Tum kar sakte ho!</i>
```

### Unknown Query (Catch-all)
```
Samajh gaya! 👍

Aapne poocha: "{txt}"

Kya aap:
1. Exam prep help?
2. Business ideas?
3. Technical help?

Number bolo ya detail do!
```

## HTML Formatting Guide
- `<b>bold</b>` — emphasis
- `<i>italic</i>` — subtle emphasis, titles
- `<code>code</code>` — inline code, UPI IDs
- Use sparingly — don't over-format
